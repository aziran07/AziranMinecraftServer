# 안내 사이트 정보 구조

2026-09-25: 메인에 설치·설정·플레이·문제 해결이 누적되어 유용한 플레이 정보가
긴 설치 안내 아래로 밀린 문제를 해결한다. 시각 기준은 루트 `DESIGN.md`다.

## 페이지와 우선순위

| 페이지 | 담당 내용 |
| --- | --- |
| `index.html` | 간결한 서버 소개, 다운로드·주소 복사, 플레이 가이드 카드, 설치·도움말 입구 |
| `join.html` | 준비물, 기존 4단계 설치, Java 설정 스크린샷, 버전별 업데이트 안내 |
| `play.html` | 여행자의 배낭, Nemo 정렬, JourneyMap, 명령어·Occultism·웹 지도 연결 |
| `visuals.html` | 셰이더 켜기·끄기, 리소스팩 기본값·순서·한국어 설정 |
| `help.html` | 두 번째 실행 멈춤의 원인과 수정 절차, Java 안내 연결, Discord 문의 |
| `commands.html`, `occultism.html` | 기존 본문 유지, 공통 탐색과 관련 링크 갱신 |

메인의 다운로드·주소 복사는 첫 화면의 주 행동이다. 바로 다음에는 웹 지도,
명령어, Occultism, 배낭, 정렬, 화면 설정을 동등한 가이드 카드로 배치한다.
설치 상세·전체 사양·Java 이미지·버전 변경 설명은 메인에 반복하지 않는다.
메인 텍스트 분량은 기존의 40% 이하를 목표로 하되 필수 에디션·버전과 다운로드 주의는 보인다.

로고는 홈으로, 공통 메뉴는 설치·플레이·화면 설정·명령어·도움말 5개로 통일한다.
Occultism은 메인 카드와 플레이 페이지에서 바로 접근한다. 각 상세 페이지는
본문보다 부가정보가 먼저 쌓이지 않도록 모바일 읽기 순서를 정하고, 관련 가이드로 연결한다.

## 시각 설계

- 기존 청보라 베벨 패널·짙은 탐색 바·주황색 행동 강조를 유지한다.
- SVG로 지도·집·책·배낭·정렬·화면을 구분하는 간단한 픽셀풍 아이콘을 만든다.
  아이콘은 제목을 보조하며 텍스트 라벨을 대체하지 않는다. 외부 아이콘 의존성은 추가하지 않는다.
- 기존 실제 Java 설정 이미지는 설치 안내에 보존한다. 가짜 게임 스크린샷은 만들지 않는다.
- 카드 전체를 클릭할 수 있게 하고 키보드 포커스와 44px 이상 주요 조작 영역을 보장한다.
- 360px·768px·1280px에서 가로 넘침 없이 읽히며, 모바일에서 가이드보다 사양이 먼저 나오지 않는다.

## 이동 시 보존할 내용

팩 1.1.10의 다운로드 URL·21개 모드, Java 25, NeoForge 버전과 Java Edition 전용 조건을 유지한다.
Iris 개발 빌드, 새 인스턴스 설치, 기존 버전 호환, 리소스팩 우선순위·호환 한계,
단축키 충돌·정렬 조작, 확인하지 않은 게임 동작의 제한 설명을 적절한 상세 페이지에 보존한다.
문의·공식 출처 링크와 기존 명령어·Occultism 콘텐츠를 잃지 않는다.

기존 메인 북마크 `#steps`, `#java`, `#extras`, `#resourcepacks`, `#backpack`,
`#sorting`, `#webmap`, `#keys`, `#help`는 해당 가이드로 가는 짧은 링크에 앵커로 남긴다.
기존 사이트 내부 링크는 새 페이지의 정확한 위치를 직접 가리키게 갱신한다.
북마크 지원 때문에 긴 설명을 다시 메인에 넣거나 자동 리다이렉트 스크립트를 추가하지 않는다.

## 소유권과 검증

Claude는 `site/` 구현만 담당한다. Codex는 이 설계와 문서, 테스트, 리뷰·검증·커밋·푸시를 담당한다.
서버 설정·팩 빌더·런타임 데이터·다운로드 산출물은 이번 변경 대상이 아니다.

자동 검사는 기존 주소 복사 성공·실패 검사와 로컬 링크·앵커·자산 무결성 검사 하나를 사용한다.
본문 문구·CSS 구조·카드 개수 고정 테스트는 추가하지 않는다.
Codex가 기존 내용과 옮긴 내용을 대조하고, 데스크톱·모바일 화면, 첫 화면의 행동,
카드·메뉴·북마크·주소 복사를 브라우저로 확인한다. 검사하지 못한 범위는 완료 보고에 명시한다.
