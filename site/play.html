여행자의 배낭

Traveler's Backpack(여행자의 배낭) 모드가 들어 있습니다. 배낭을 만들어 손에 들고 우클릭하면 열립니다. 등에 메려면 인벤토리 화면에서 Curios 창을 열고 배낭을 Back(등) 슬롯에 넣습니다. 등에 멘 배낭은 Y로 엽니다. 땅에 블록으로 놓을 수도 있습니다.

Y
등에 착용한 배낭 열기 (모드 원래 기본값은 B)
Z
배낭의 도구 바꾸기 / 호스 모드 바꾸기

왜 Y인가요? 모드의 원래 기본값 B는 Occultism 가방 열기, Tom's Simple Storage 터미널 열기, JourneyMap 웨이포인트 만들기와 겹칩니다. 그래서 1.1.9 이후 모드팩으로 새로 만든 인스턴스는 배낭 열기만 다른 모드가 쓰지 않는 Y로 정해 두었습니다. 다른 단축키는 바꾸지 않았습니다. 이미 만든 인스턴스는 B로 남으니, 필요하면 Options(설정) → Controls(조작) → Key Binds(키 설정)에서 바꾸세요.

배낭을 등에 멘 채 죽었을 때의 동작, 특히 무덤 모드와 함께 쓸 때의 동작은 아직 게임에서 확인하지 않았습니다.

인벤토리 정렬 버튼

1.1.10부터 Nemo's Inventory Sorting 모드가 들어 있습니다. 인벤토리(E)나 상자 같은 보관함 화면을 열면 칸 옆에 작은 버튼이 생기고, 마우스를 올리면 이름이 영어로 보입니다(이 모드에는 한국어 번역이 없습니다). 라이선스상 모드팩 파일에 담을 수 없어서 .mrpack을 가져올 때 런처가 Modrinth에서 직접 내려받습니다.

Sort (정렬)
그 칸 묶음(보관함 또는 내 인벤토리)의 아이템을 정리해 줍니다.
Move Same (같은 것 옮기기)
반대편에 이미 있는 종류의 아이템만 옮깁니다. 예를 들어 상자에 들어 있는 종류만 내 인벤토리에서 상자로 넣습니다.
Move All · Drop All
모든 아이템을 반대편으로 옮기거나(Move All) 바닥에 버립니다(Drop All). 버리기는 잘못 누르지 않도록 조심하세요.

핫바는 기본으로 빠집니다. 내 인벤토리 쪽 버튼을 그냥 누르면 아래 9칸(핫바)은 건드리지 않습니다. 핫바까지 포함하려면 Shift를 누른 채 버튼을 누르세요. Alt(맥은 Option)를 누른 채 칸을 클릭하면 그 칸을 잠가 정렬·옮기기에서 뺄 수 있고, Ctrl + F로 아이템을 검색할 수 있습니다.

단축키는 따로 정해 두지 않았습니다. 버튼만으로 쓸 수 있고, 원하면 Options(설정) → Controls(조작) → Key Binds(키 설정)의 Nemo's Inventory Sorting 항목에서 지정하세요. 이 모드의 Shift+끌기·Shift+우클릭·휠 이동 기능은 모드팩 설정 파일에서 꺼 두었습니다. 원래 있던 Mouse Tweaks의 조작은 그대로입니다.

이미 만든 인스턴스에는 저절로 들어가지 않습니다. 기존 인스턴스에 넣으려면 모드 파일과 설정 파일 config/nemos-inventory-sorting/general.json을 직접 넣어야 합니다. 방법은 배포 페이지의 README.md에 있습니다. 새 인스턴스로 가져오는 쪽이 간단합니다.

정렬 버튼의 실제 동작과, 배낭·Tom's Simple Storage 터미널·Occultism 저장고처럼 모드가 만든 전용 화면에서 버튼이 제대로 동작하는지는 아직 게임에서 확인하지 않았습니다. 이상하면 그 화면에서는 버튼을 쓰지 말고 알려 주세요.

미니맵

미니맵은 JourneyMap입니다. 게임에 들어가면 화면 구석에 미니맵이 보이고, 전체 지도는 기본 단축키 J로 엽니다. JourneyMap은 라이선스상 모드팩 파일에 담을 수 없어서, .mrpack을 가져올 때 런처가 Modrinth에서 직접 내려받습니다.

BlueMap 웹 지도

월드 지도는 BlueMap 웹 지도로 브라우저에서 볼 수 있습니다. 게임에 들어가지 않아도 되고, 별도 클라이언트 모드를 설치할 필요도 없습니다. 아직 지도에 그려지지 않은 지역은 비어 보일 수 있습니다.
