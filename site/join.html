모드팩 Aziran 26.3 Client 1.1.12 · 설치 안내

Aziran 서버 설치 안내

설치하기

모드팩 파일 하나를 내려받아 런처로 가져오면 준비가 끝납니다. 아래 네 단계를 순서대로 따라 하세요.

모드팩 다운로드 aziran-26.3-client-1.1.12.mrpack 4단계 보기

알아 두세요. 모드팩 1.1.12는 셰이더를 쓰기 위해 Iris의 아직 공식 반영되지 않은 개발 버전을 직접 빌드해 담았습니다. 문제가 생기면 오류 내용을 알려 주세요.

접속하는 방법

  1. 1Prism Launcher 설치하고 로그인하기

    1. 공식 다운로드 페이지에서 사용하는 운영체제에 맞는 Prism Launcher를 내려받아 설치합니다.
    2. 런처를 열고 오른쪽 위 계정 관리에서 정품 마인크래프트 자바 에디션 계정으로 로그인합니다.
    3. 정품 계정이 있어야 서버에 들어올 수 있습니다.

  2. 2자바 25 준비하기

    1. 이 모드팩은 Java 25가 필요합니다. 이전 버전의 자바로는 실행되지 않습니다.
    2. Java 25가 이미 설치되어 있고 Prism Launcher가 그 자바를 선택하고 있다면 다시 설치할 필요가 없습니다. 다음 단계로 넘어가세요.
    3. 설치되어 있지 않거나 선택되지 않았다면, Prism Launcher 9.0 이상에서 Settings (설정) → Java를 열고 Autodetect Java version (자바 버전 자동 감지)과 Auto-download Mojang Java (Mojang Java 자동 다운로드)를 체크합니다. 필요한 자바를 런처가 자동으로 내려받습니다.
    4. 자동으로 받을 수 없거나 자바 관련 오류가 나오면, Java 25를 직접 설치한 뒤 인스턴스를 오른쪽 클릭 → Edit → Settings → Java에서 Java 25를 선택합니다.

    Prism Launcher 공식 자바 설치 안내

  3. 3모드팩 파일 가져오기

    1. 모드팩 다운로드로 .mrpack 파일을 받습니다.
    2. 압축을 풀지 마세요. 받은 파일을 그대로 사용합니다.
    3. Prism Launcher에서 Add Instance(인스턴스 추가) → Import from zip(불러오기) 탭을 엽니다.
    4. 내려받은 .mrpack 파일을 선택하고 가져오기를 끝냅니다.
    5. 이전에 만든 인스턴스에 덮어쓰지 말고 새 인스턴스로 만듭니다.

    가져오기가 끝나면 마인크래프트 26.3, NeoForge 26.3.0.8-beta, 모드 22개와 셰이더 팩, 리소스팩 3개가 함께 설치됩니다. 모드 대부분과 셰이더 팩, 일부 리소스팩은 런처가 내려받으므로 인터넷 연결이 필요합니다. 새 인스턴스는 게임 언어가 한국어로 시작합니다.

    이전 모드팩을 쓰던 분은 아래 업데이트 안내를 먼저 확인하세요.

    Prism Launcher 공식 가져오기 안내

  4. 4서버 접속하기

    1. 가져온 인스턴스를 선택하고 실행합니다. 첫 실행은 파일을 내려받느라 오래 걸릴 수 있습니다.
    2. 게임이 열리면 Multiplayer(멀티플레이)를 누릅니다.
    3. 1.1.5 이후 모드팩으로 새로 만든 인스턴스에는 목록에 Aziran(mc.aziran.uk) 서버가 이미 들어 있습니다. 이 서버를 눌러 접속합니다.

    목록에 서버가 없다면(이전에 만든 인스턴스 등) Add Server(서버 추가)를 누르고 서버 주소 칸에 mc.aziran.uk 를 입력한 뒤 완료를 누르세요.

이전 모드팩을 쓰던 분

1.1.12는 등(Back) 슬롯에 멘 배낭의 내용이 저장되게 하는 서버 패치를 싱글플레이용으로 함께 담은 판입니다. 나머지 모드와 설정은 1.1.11과 같습니다. 멀티플레이에서는 서버가 이 패치를 실행하므로 1.1.11 인스턴스도 그대로 접속할 수 있습니다. 싱글플레이에서의 동작은 요청에 따라 시험하지 않았습니다.

  • 새로 설치할 때는 위의 1.1.12 모드팩을 가져오면 번역 팩과 배낭 패치가 이미 들어 있습니다.
  • 1.1.10부터 들어 있는 정렬 버튼을 쓰려면 1.1.10 이후 모드팩을 새 인스턴스로 가져와 주세요. 기존 인스턴스에 직접 넣는 방법은 인벤토리 정렬 안내에 있습니다.
  • 배낭 모드가 없는 1.1.8 이하 인스턴스로는 접속할 수 없습니다.
  • 게임 언어·리소스팩 기본값과 배낭 단축키 Y는 새로 가져온 인스턴스에만 적용됩니다. 기존 인스턴스는 화면 설정과 배낭 안내를 보고 직접 바꾸세요.
