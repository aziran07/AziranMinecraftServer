자바 에디션 전용입니다. 모바일·콘솔·Windows 스토어에서 쓰는 베드락 에디션으로는 접속할 수 없습니다. 마인크래프트와 NeoForge, 모드는 아래 2단계에서 런처가 함께 설치합니다. 자바는 아래 자바 25 준비를 보세요.

접속하는 방법

  1. 1Prism Launcher 설치하고 로그인하기

    1. 공식 다운로드 페이지에서 사용하는 운영체제에 맞는 Prism Launcher를 내려받아 설치합니다.
    2. 런처를 열고 오른쪽 위 계정 관리에서 정품 마인크래프트 자바 에디션 계정으로 로그인합니다.
    3. 정품 계정이 있어야 서버에 들어올 수 있습니다.

    Prism Launcher 공식 다운로드

  2. 2모드팩 파일 가져오기

    1. 맨 위의 모드팩 다운로드 버튼으로 .mrpack 파일을 받습니다.
    2. 압축을 풀지 마세요. 받은 파일을 그대로 사용합니다.
    3. Prism Launcher에서 Add Instance(인스턴스 추가) → Import from zip 탭을 엽니다.
    4. 내려받은 .mrpack 파일을 선택하고 가져오기를 끝냅니다.
    5. 이전에 만든 인스턴스에 덮어쓰지 말고 새 인스턴스로 만듭니다.

    가져오기가 끝나면 마인크래프트 26.3, NeoForge 26.3.0.8-beta, 모드 16개가 함께 설치됩니다. 모드 대부분은 런처가 내려받으므로 인터넷 연결이 필요합니다.

    Prism Launcher 공식 가져오기 안내

  3. 3서버 접속하기

    1. 가져온 인스턴스를 선택하고 실행합니다. 첫 실행은 파일을 내려받느라 오래 걸릴 수 있습니다.
    2. 게임이 열리면 Multiplayer(멀티플레이) → Add Server(서버 추가)를 누릅니다.
    3. 서버 주소 칸에 mc.aziran.uk 를 입력하고 완료를 누릅니다.
    4. 목록에 생긴 서버를 눌러 접속합니다.

자바 25 준비

이 모드팩은 Java 25가 필요합니다. Prism Launcher 9.0 이상은 Settings → Java에서 Autodetect Java version과 Auto-download Mojang Java를 켜면 자바를 자동으로 내려받습니다.

자동으로 받은 자바가 맞지 않아 실행 중 자바 관련 오류가 나오면, Java 25를 직접 설치한 뒤 인스턴스를 오른쪽 클릭 → Edit → Settings → Java에서 Java 25를 선택하세요.
